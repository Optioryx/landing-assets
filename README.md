# landing-assets

Generated output of the private `Optioryx/marketing-landing-page-harness` repo, published here so jsDelivr
can serve it. Do not edit by hand; every file is overwritten on the next publish.

Served at `https://cdn.jsdelivr.net/gh/Optioryx/landing-assets@v<version>/...`. Tags are never
moved because jsDelivr caches them permanently.
